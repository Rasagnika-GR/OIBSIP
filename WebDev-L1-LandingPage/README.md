# Plot Twist — Enter the Mystery
## Description

**Plot Twist — Enter the Mystery** is a cinematic mystery-themed landing page created as part of the Oasis Infobyte Web Development and Designing internship.

The page introduces a fictional unsolved case, presents the people connected to it, and reveals key pieces of evidence through an immersive case-file inspired design.
## Features

- Sticky navigation bar with smooth scrolling
- Cinematic mystery-themed hero section
- Fictional case-file presentation
- Case investigation story section
- Three suspect profiles
- Evidence log with key clues
- Responsive design for desktop, tablet, and mobile screens
- Consistent dark, red, and paper-inspired visual theme
- Hover effects and interactive visual elements using CSS
## Technologies Used

- HTML5
- CSS3
- CSS Grid
- CSS Flexbox
- Responsive Web Design

## How to Run the Project

1. Download or clone this repository.
2. Open the `WebDev-L1-LandingPage` folder.
3. Open `index.html` in your web browser.
4. Explore the landing page and navigate through its sections.
