# Temperature Converter

A simple and user-friendly temperature conversion application built as part of the Oasis Infobyte Web Development Internship.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Convert temperatures between Celsius, Fahrenheit, and Kelvin.
- Input validation.
- Clear conversion results.
- Simple and responsive user interface.

## How to Run
1. Download or clone this project.
2. Open `index.html` in a web browser.
3. Enter a temperature, select the units, and click Convert.
