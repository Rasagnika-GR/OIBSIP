# Personal Portfolio

A personal portfolio website showcasing my skills, projects, and journey as an aspiring developer. Created as part of the Oasis Infobyte Web Development Internship.

## Technologies Used
- HTML5
- CSS3

## Features
- Personal introduction and About section.
- Skills and currently learning sections.
- Project cards with GitHub links.
- Contact section with email functionality.
- Responsive Bento Grid layout.
- Smooth navigation.

## Projects Showcased
1. Plot Twist – Mystery-themed landing page.
2. Temperature Converter – Temperature conversion application.
3. Word Guessing Game – Python and Streamlit-based game.

## How to Run
1. Download or clone this project.
2. Open `index.html` in a web browser.
